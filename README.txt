EduTrack - Student Management System (Servlet + JSP + REST, no database)
Requires: JDK 17+, Eclipse IDE for Enterprise Java and Web Developers, Apache Tomcat 11

IMPORT: File -> Import -> General -> Existing Projects into Workspace -> select the StudentApp folder -> Finish
RUN:    Right-click project -> Run As -> Run on Server -> Apache Tomcat v11.0 -> Finish
OPEN:   http://localhost:8080/StudentApp/

If "Target runtime not defined" appears: Window -> Preferences -> Server -> Runtime Environments -> Add Tomcat 11,
then Project -> Properties -> Targeted Runtimes -> tick Tomcat 11 -> Apply, then Project -> Clean.
